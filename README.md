# danielrojasm-airbnb

Proyecto base con Next.js 16, TypeScript, Tailwind CSS y App Router.

## Empezar

```bash
npm install
npm run dev
```

Abre http://localhost:3000 para ver la app.

## Estructura

- `app/`: rutas con App Router.
- `components/`: piezas de UI reutilizables.
- `app/globals.css`: estilos globales y Tailwind.
